# VA Math

**Built by a veteran for veterans.**

Independent educational Progressive Web App that explains how VA disability ratings are combined under official rules (38 CFR §4.25 + §4.26).

Not affiliated with, endorsed by, or operated by the U.S. Department of Veterans Affairs.

## Status

Early scaffold — Motionsites liquid-glass system, zero-scroll dashboard, pure calculation engine.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS (liquid-glass design system)
- Offline-first PWA
- Pure calculation engine from locked 38 CFR Part 4 (30 Jul 2026)

## Development

```bash
npm install
npm run dev
```
